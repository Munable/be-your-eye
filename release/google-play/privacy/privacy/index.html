中文

本政策说明 Be Your Eye 产品运营者（“我们”）如何在帮你盯 Android 应用中处理数据。参考图片、数字读数和文字描述目标／现象三条监控路线都在本机运行。产品能力要求登录并具有有效试用或付费使用权；账号、恢复购买、管理订阅、删除账号、法律页面和本机只读历史在锁定状态仍可访问。账号与权益校验、同步、AI 配置助手和语音输入需要联网。

1. 本机视觉数据

  • 普通相机帧、临时选区、视觉中间结果和实时推理只在设备内存处理，不上传到 AI、账号服务、数据库、对象存储、推送或订阅服务。
  • 用户选择的参考图片和每次目标出现最多一张触发图保存在 App 私有目录并禁止系统备份；删除任务或卸载 App 时删除。
  • 同账号用户从另一台在线手机主动查看触发图时，来源手机才发送一张不超过 720 px／120 KiB 的端侧加密临时副本。Supabase Realtime 只中继请求元数据和密文且不持久化；查看端副本只进入 App 私有临时缓存。
  • 本机任务、事件时间线、设置和签名模型包保存在设备上。模型包不带独立计费档位；创建、下载和运行统一服从账号的产品权益。

2. 账号、恢复和同步

用户登录后会自动启用同账号同步。我们通过 Supabase 处理邮箱、账号标识、加密 session、设备标识、已确认的任务摘要、结构化事件和送达状态，用于登录、密码恢复、权益校验和同账号同步。恢复邮件包含一次性 App Link。云端事件不含照片、视频或音频；Event payload 自服务端收到起保留 30 天。删除账号会删除关联的账号、设备、任务、事件、回执、投递和权益记录。

只有在用户开启同账号事件提醒时，App 才启用 Firebase Cloud Messaging，并处理 FCM token、Firebase Installation ID、App 版本和 Firebase user agent（包含操作系统版本、设备型号／品牌／形态、安装来源和 Firebase SDK 版本）以完成推送。我们不包含 Firebase Analytics、Crashlytics 或 Performance Monitoring，也不启用 FCM BigQuery 送达指标导出。

App 不请求 Android 位置权限，也不提供用户级位置功能。云端请求会携带 IP，Supabase/Cloudflare Edge 网络日志可处理由 IP 得到的国家／地区等粗略位置元数据，只用于传输、运行和安全，不用于广告或个性化。

3. AI、语音和 Pro

  • AI 配置助手：用户主动发送的文字、必要的有限对话上下文和 Catalog 能力摘要，经 Be Your Eye Supabase Edge Function 发送给 Alibaba Cloud Model Studio 托管的 DeepSeek。内容只用于当前请求；我们不建立云端对话表、不在 App／Edge 日志中记录正文，并保持 Model Studio 的 Prompt/Response inference logs 关闭。不会发送相机帧、参考图片、触发图或本地事件。
  • 语音输入：仅在用户长按说话时录制一次最长 30 秒、最多 512 KiB 的 AAC/MPEG-4，经同一 Edge 边界发送给 Alibaba Qwen ASR。录音在转写成功、失败或取消后从本机缓存删除，不建立云端 audio/transcript 数据表，服务日志不记录音频或转写正文。
  • 官网账号与付款：官网使用同一 Supabase 账号，登录会话保存在当前浏览器标签页的 sessionStorage，退出时清除，不写入长期 localStorage。Stripe 收银台处理银行卡或钱包付款，我们不接触支付卡完整资料。服务器保存订单标识、Stripe 付款标识、金额、币种、付款／退款状态和使用期限；Stripe 接收随机订单标识，不接收你的相机图像或账号密码。删除账号后交易记录解除账号关联，只用于退款、争议和必要财务记录。
  • Pro 订阅：Google Play 处理购买和付款。App 可读取订阅商品、状态和到期时间，并将 purchase token 瞬时提交给 Edge，再由 Android Publisher API 校验；数据库只保留 token 的 SHA-256、商品、状态和到期时间，不保留原始 token 或支付卡资料。
  • 运行元数据：为运行、防止滥用和排查故障，云服务可保留不含用户内容的请求时间、状态、request ID、模型／token 用量和时延，保留期按当前服务计划和安全需要限定。
  • 访问限制：监控创建和运行、全部模型下载和运行、AI 助手、语音转写及同步均要求登录并具有有效试用或付费使用权。

4. 权限

  • Camera：用于用户主动开始的本地视觉分析和监控。
  • Microphone：仅在用户长按 AI 输入栏说话时录制本次语音；不会后台录音。
  • Notifications：仅在用户开启相应设置后显示运行状态或事件提醒。
  • Internet：用于账号和权益校验、签名模型包、同步／推送、AI、语音及密码恢复。

5. 服务提供商与安全

我们使用 Supabase 提供 Auth、数据库、Realtime 和 Edge Functions，Alibaba Cloud DirectMail 投递账号确认、恢复和安全邮件，Cloudflare R2/Pages 分发签名模型包与本政策，Firebase Cloud Messaging 提供可选推送，Alibaba Cloud Model Studio 提供 DeepSeek 与 Qwen ASR，Google Play 提供订阅、校验和状态通知，Stripe 处理官网付款。这些提供商按合同和数据处理条款代我们处理完成服务所需的数据。我们不出售用户数据，也不授权服务提供商将这些数据用于跨客户行为广告。网络请求使用 HTTPS；账号 session 以 Android Keystore 保护的密文保存且不进入系统备份。

6. 选择、联系与变更

用户可以拒绝麦克风、关闭通知、管理或取消 Play 订阅、删除任务及其本机素材，也可以在 App 内删除云端账号。权益失效后，本机历史仍保持只读。隐私与支持问题请联系 support@beyoureye.com；涉及漏洞、密钥或用户数据的报告请使用私密安全报告入口，不要提交到公开 Issue。政策有实质变化时，我们会更新生效日期并按适用要求提示。

删除账号 / Delete account

已登录用户可在 App 的“账号与其他手机”页面选择“删除云端账号”并确认。无法访问 App 时，请从注册邮箱发邮件至 support@beyoureye.com，主题写明“Be Your Eye account deletion”。我们可能只进行确认账号归属所必需的验证，不要求重新安装 App。

删除完成后，关联的云端账号、设备、任务摘要、结构化事件、回执、推送和权益记录会删除。本机数据独立保存在设备上；如需一并删除，请在 App 内删除任务或卸载 App。删除 Be Your Eye 账号不会自动取消 Google Play 订阅；如需停止续费，请先在 Google Play 管理订阅。

Signed-in users can choose “Delete cloud account” from “Account and other phones” in the app and confirm. If the app is unavailable, email support@beyoureye.com from the registered address with the subject “Be Your Eye account deletion.” We may perform only the verification needed to confirm ownership; reinstalling the app is not required. Deleting a Be Your Eye account does not cancel a Google Play subscription; manage the subscription in Google Play first to stop renewal.

English

This policy explains how the operator of Be Your Eye (“we”) handles data in the Be Your Eye Android app. The reference-image, numeric-reading, and described-target-or-phenomenon routes all run on the device. Product features require sign-in and an active trial or paid access; account access, purchase restoration, subscription management, account deletion, legal pages, and read-only local history remain available while locked. Account and entitlement checks, sync, the AI configuration assistant, and voice input require network access.

1. Visual data on the device

  • Ordinary camera frames, temporary regions, intermediate visual results, and live inference are processed only in device memory. They are not uploaded to AI, account, database, object-storage, push, or subscription services.
  • User-selected reference images and at most one trigger image per target appearance stay in private app storage and are excluded from system backup. They are removed when the task is deleted or the app is uninstalled.
  • Only when a same-account user requests a trigger image from another online phone does the source phone send a client-side-encrypted temporary copy of no more than 720 px / 120 KiB. Supabase Realtime relays only request metadata and ciphertext without persistence; the viewer copy enters only private temporary app cache.
  • Local tasks, event timelines, settings, and signed model packages remain on the device. Model packages have no separate billing tier; creation, download, and runtime use the account-level product entitlement.

2. Account, recovery, and sync

Signing in automatically enables same-account sync. Supabase processes an email address, account identifier, encrypted session, device identifier, confirmed task summaries, structured events, and delivery status for sign-in, password recovery, entitlement verification, and same-account sync. Recovery emails contain a one-time App Link. Cloud events contain no photo, video, or audio. Event payloads are retained for 30 days after server receipt. Account deletion removes the associated account, device, task, event, receipt, delivery, and entitlement records.

Only when the user enables same-account event alerts does the app enable Firebase Cloud Messaging and process an FCM token, Firebase Installation ID, app version, and Firebase user agent (including OS version, device model/brand/form factor, installer, and Firebase SDK versions) to deliver push messages. We do not include Firebase Analytics, Crashlytics, or Performance Monitoring and do not enable FCM BigQuery delivery-metrics export.

The app does not request Android location permission or provide a user-level location feature. Cloud requests carry an IP address, and Supabase/Cloudflare Edge network logs may process coarse country/region metadata derived from it solely for transport, operations, and security—not advertising or personalization.

3. AI, voice, and Pro

  • AI configuration assistant: text actively submitted by the user, limited context needed for clarification, and a Catalog capability summary pass through a Be Your Eye Supabase Edge Function to DeepSeek hosted by Alibaba Cloud Model Studio. Content is used only for the current request; we do not create a cloud conversation table, log content in the app or Edge Function, or enable Model Studio inference logs that store prompts and responses. Camera frames, reference images, trigger images, and local events are not sent.
  • Voice input: only while the user holds the talk control, the app records one AAC/MPEG-4 clip of up to 30 seconds and 512 KiB and sends it through the same Edge boundary to Alibaba Qwen ASR. The cache file is deleted after success, failure, or cancellation. No cloud audio/transcript table is created, and service logs contain neither audio nor transcript content.
  • Website accounts and payments: The website uses the same Supabase account and stores its session in the current browser tab sessionStorage. Signing out clears it; we do not persist it in localStorage. Stripe Checkout handles card or wallet payments; we do not receive full payment-card details. Our server retains order and Stripe payment identifiers, amount, currency, payment/refund state and access term. Stripe receives a random order identifier, not camera images or account passwords. After account deletion, transaction records are detached and kept only for refunds, disputes and necessary financial records.
  • Pro subscription: Google Play handles purchase and payment. The app reads the subscription product, status, and expiry and submits a purchase token transiently to Edge for Android Publisher API verification. The database retains only the token SHA-256, product, status, and expiry—not the raw token or payment-card details.
  • Operational metadata: to operate the service, prevent abuse, and diagnose failures, cloud services may retain request time, status, request ID, model/token usage, and latency without user content. Retention is limited by the current service plan and operational-security need.
  • Access gate: monitor creation and runtime, all model download and runtime, the AI assistant, voice transcription, and sync require sign-in and an active trial or paid access.

4. Permissions

  • Camera: local visual analysis and monitoring started by the user.
  • Microphone: recording of the current voice input only while the user holds the AI talk control; no background recording.
  • Notifications: running-state or event alerts only when the related setting is enabled.
  • Internet: account and entitlement checks, signed model packages, sync/push, AI, voice, and password recovery.

5. Providers and security

We use Supabase for Auth, database, Realtime, and Edge Functions; Alibaba Cloud DirectMail for account-confirmation, recovery, and security emails; Cloudflare R2/Pages for signed model packages and this policy; Firebase Cloud Messaging for optional push; Alibaba Cloud Model Studio for DeepSeek and Qwen ASR; Google Play for subscriptions, verification, and state notifications; and Stripe for website payments. These providers process the data needed to deliver their services on our behalf under their contracts and data-processing terms. We do not sell user data or authorize providers to use it for cross-context behavioral advertising. Network requests use HTTPS. Account sessions are stored as Android-Keystore-protected ciphertext and are excluded from system backup.

6. Choices, contact, and changes

Users may deny microphone access, disable notifications, manage or cancel the Play subscription, delete a task and its local material, and delete the cloud account in the app. Local history remains read-only after entitlement expiry. For privacy and support questions, contact support@beyoureye.com. Report vulnerabilities, secrets, or user-data exposure through the private security-report channel, not a public issue. If this policy changes materially, we will update the effective date and provide any required notice.
