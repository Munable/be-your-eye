# 设备与网络范围

[English](DEVICE_SUPPORT.md) · [构建与安装](BUILD.zh-CN.md) · [使用说明](../../USER_MANUAL.zh-CN.md)

安装要求 Android 8 / API 26 或更新系统、arm64-v8a。当前签名模型要求标称 8192 MB 内存。Community 不包含 Firebase Messaging 或 Play Billing，不依赖 Google Play 服务。尚未作出 4 GB / 6 GB 设备上的识别性能承诺。

8 GB 识别要求适用于监控手机。只接收配对文字提醒的手机不加载视觉模型，收信本身不需要相机；扫码是可选的，也可以输入复制的配对码。接收端仍需能够安装 Community 应用、联网、允许通知并主动开启收信。4 GB、API 36 模拟器曾收到测试提醒，这不是真机支持列表，也不保证所有 4 GB 手机都可用。

当前测试记录见[发布证据（英文）](../../evidence/current/05-release.json)。arm64、API 36 模拟器通过了全新调试版启动检查和单独的已签名发布版冷启动；启动成功本身不能证明模型或相机能力。后来的[演示录制（英文）](demos/SOURCES.md)通过模拟器的视频文件摄像头，实际运行了 Community 数字、行人和参考图识别，并核实本机事件记录。这仍属于受控回放，不是真机自然场景验收。

PJA110 / API 36 曾以错误 -99 拒绝新包安装，需要机主在手机上授权。已有旧版安装和资料未被删除。用相机拍电脑屏幕同样属于回放证据，不能证明自然物体准确率。真实物体或显示屏触发、代表性的 1–2 小时运行、以及用户独立操作，均需实际记录后才能完成验收。

大陆不使用代理和海外环境的页面、APK、模型可达性需要分别检查。开发 Mac 上请求成功只证明该网络路径。目前公开 APK 下载仍待完成。

监控时固定手机，持续供电，使用竖屏后置相机并保持应用可见。离开应用或锁屏会停止拍摄；达到临界温度时也会停止，且不会悄悄自动恢复。接收端的联网和电池限制另见[配对指南](PAIRING.zh-CN.md)。
