# Neural-reference third-package contract fixture

This is deliberately non-executable test data. `primary.fixture` is not a real LiteRT model and the
license fields deliberately prevent commercial use. It proves that a third package can describe the
same `similarity_match_v1` + `class_agnostic_localize_letterbox_multi_crop_rgb_v3` +
`similarity_logit_state_v1` graph using only a Manifest and artifact bytes. Every imported reference
participates; the deleted direct-resize and runtime-cohesion paths fail closed, and production Android
source contains no reference to this package ID.
