Be Your Eye turns a continuously powered Android phone into a fixed-camera visual monitor.

First-release capabilities
• Reference-image monitoring: add 3–20 photos of one target and record when it appears, remains in view, or disappears. Import rejects only unreadable or duplicate photos; every accepted photo contributes to the reference set. The material indicator shows reference coverage, not an accuracy score.
• Fixed numeric-display reading: monitor one single-line display, optionally draw a strict reading area, preview the app's stable interpretation, confirm it, and then set an above, below, or outside-range event condition.
• Text-described target search: describe a visible target or phenomenon covered by an exact active package in the signed Catalog, confirm it in the rear-camera preview, and monitor only that target. If the Catalog has no exact active coverage—including a requested specialist industrial model—the task remains unavailable instead of falling back to a similar class.

Local first
• Camera frames and live visual inference stay on the phone.
• Reference photos remain in the app's private storage and are excluded from system backup.
• Product features require sign-in and an active trial or subscription. Model packages have no separate billing tier. Local history remains read-only if access expires.
• Quiet local notifications can be enabled per task.

One subscription, all features
Google Play returns the local monthly and annual prices, with annual selected by default. A one-time 3-day full-feature trial is shown only when Play says the account is eligible; returning subscribers see immediate billing. Both plans include all features and unlimited devices on the same account. You can restore purchases or manage the subscription in Google Play.

Pro configuration assistant
Type or hold to talk to a concise multi-turn assistant. It asks for missing details, then opens a reviewable prefilled monitor setup; it never creates or starts a task without confirmation. Voice sends only the current bounded recording for Qwen transcription, deletes the local recording afterward, and uses the same assistant flow.

Multi-device sync
Task summaries and structured events automatically sync between phones on the same account. Each phone controls notifications for events from other phones. Cloud events never contain photos, video, or audio, and the account can be deleted in the app. Deleting the account does not cancel Google Play billing.

Operating boundary
Be Your Eye is designed for a fixed position, portrait rear camera, continuous power, and one active monitoring task at a time. Results vary with framing, obstruction, lighting, target size, and display clarity. Preview and confirm the setup before relying on an event condition. The app is not a security alarm, life-safety system, or certified measuring instrument.
